Excel Sales Analysis Project

Project Overview

This project analyzes sales data using Microsoft Excel to organize data, perform calculations, and present information through a dashboard.

Tools Used

- Microsoft Excel
- Excel formulas and calculations
- Charts and data visualization
- Dashboard creation

Workbook Sheets

- Raw Data: Contains the practice sales dataset.
- Calculations: Contains calculations used for the analysis.
- Dashboard: Presents the sales analysis visually.

Project Objective:
To practice data analysis skills, summarize sales data, and present useful information through charts and a dashboard.

Dataset:
Practice dataset sourced from the internet.

Project File
Excel workbook: "Excel_Sales_Analysis.xlsx"

Key Insights
- Regional Sales: The East region recorded the highest total sales among Central, East, South, and West.
- Quarterly Sales Trends: The dashboard compares quarterly sales across 2016 and 2017.
- Segment Analysis: A donut chart visualizes quantity across Consumer, Corporate, and Home Office segments.
- Interactive Dashboard: Slicers allow users to explore the data by region, segment, and ship mode.
